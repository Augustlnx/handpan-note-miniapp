# 图标说明

本文件夹需要放置 TabBar 所需的图标文件。

## 所需图标

请准备以下 6 个图标文件：

### 1. 记谱图标
- `notation.png` - 未选中状态（建议颜色：#8FB9AB）
- `notation-active.png` - 选中状态（建议颜色：#314D63）

### 2. 节拍器图标
- `metronome.png` - 未选中状态（建议颜色：#8FB9AB）
- `metronome-active.png` - 选中状态（建议颜色：#314D63）

### 3. 设置图标
- `settings.png` - 未选中状态（建议颜色：#8FB9AB）
- `settings-active.png` - 选中状态（建议颜色：#314D63）

## 图标规格

- **尺寸**: 81×81 像素（推荐）
- **格式**: PNG（支持透明背景）
- **大小**: 每个文件不超过 40KB

## 图标设计建议

1. **记谱图标**: 可以使用音符、五线谱或手碟相关的图标
2. **节拍器图标**: 经典的三角形节拍器图案或节奏符号
3. **设置图标**: 齿轮图标或调节旋钮图标

## 在线图标资源

如果您没有设计工具，可以从以下网站下载免费图标：

- [Iconfont](https://www.iconfont.cn/) - 阿里巴巴矢量图标库
- [IconPark](https://iconpark.oceanengine.com/) - 字节跳动图标库
- [Flaticon](https://www.flaticon.com/) - 国际图标资源
- [Icons8](https://icons8.com/) - 可调色图标库

## 临时解决方案

在正式图标到位前，您可以：
1. 使用纯色方块作为占位符
2. 从图标库下载相似图标
3. 使用 emoji 转换为图片（效果可能不理想）

## 替换图标后

记得在微信开发者工具中刷新项目，确保新图标生效。
