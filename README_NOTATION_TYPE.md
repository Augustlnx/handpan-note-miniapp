# 🎵 Handpan Note - 谱式转换功能

## 功能介绍

为 Handpan Note 微信小程序添加了强大的**谱式转换**功能，支持数字谱和简谱之间的灵活切换。

### 核心功能

- 🔄 **双向转换**：数字谱 ↔️ 简谱
- 📊 **智能数据迁移**：保留或清空原有数据
- 🎨 **自定义转换表**：支持自定义转换规则
- 📝 **修饰符支持**：完美支持高低音标记（`^.` 上方加点，`_.` 下方加点）
- 💾 **数据持久化**：转换后自动保存

---

## 快速开始

### 位置
标题区域 → 拍号下方 → "谱式" 功能行

### 基本步骤
1. 点击"谱式"功能
2. 选择目标谱式（数字谱/简谱）
3. 选择数据处理方式（保留/清空）
4. 点击"确定"

---

## 转换表示例

### 默认转换表（数字谱 → 简谱）
```
1 → 3         6 → 1^. (上方加点)
2 → 4         7 → 2^.
3 → 5         8 → 3^.
4 → 6         9 → 5^.
5 → 7         D → 6_. (下方加点)
```

### 自定义转换表
支持自定义规则，每行一条，格式：`源-目标`

```
1-3
2-4
6-1^.
D-6_.
```

## 功能特性

### 🎯 谱式转换
- 数字谱 → 简谱：按照转换表规则转换所有音符
- 简谱 → 数字谱：使用反向转换表进行逆转换
- 修饰符识别和保留：自动处理 `^.` 和 `_.` 标记

### 💡 灵活的数据处理
- **迁移模式**（默认）：原有数据按转换规则转换
- **清空模式**：删除所有音符，保留谱面骨架

### 🎨 自定义转换表
- 实时格式验证
- 清晰的错误提示
- 预设和自定义选项

### 🖥️ 用户界面
- 简洁美观的模态框
- 直观的控制选项
- 清晰的状态显示

## 使用示例

### 场景 1：简单转换
```
用户在数字谱模式中输入了一些音符。
点击"谱式" → 选择"简谱" → 点击"确定"
→ 所有数字音符自动转换为对应的简谱音符
```

### 场景 2：自定义规则
```
用户需要特定的转换规则。
点击"谱式" → 勾选"自定义转换表" 
→ 输入自定义规则 → 点击"确定"
→ 使用自定义规则进行转换
```

### 场景 3：清空数据
```
用户想在不保留数据的情况下切换谱式。
点击"谱式" → 取消"迁移当前谱面数据"
→ 选择目标谱式 → 点击"确定"
→ 数据清空，谱式切换完成
```

## 常见问题

**Q：转换会影响原有数据吗？**  
A：可以选择。勾选"迁移数据"会保留并转换原数据；取消则清空数据。

**Q：如何返回之前的谱式？**  
A：再次打开转换窗口，选择原来的谱式即可。

**Q：8^. 在哪里输入？**  
A：在简谱模式的音符输入框中直接输入 "8^." 即可。

**Q：支持哪些修饰符？**  
A：支持 `^.`（上方加点）和 `_.`（下方加点）两种。
